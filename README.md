# The UX Review

A responsive, neo-brutalist blog landing page built with **HTML and CSS**. The design features bold typography, strong borders, bright colors, article previews, author profiles, and a community section.

## Features

- Responsive layout for desktop, tablet, and mobile screens.
- Sticky navigation bar with links to page sections.
- Hero section with featured image and call-to-action buttons.
- Latest articles section with categories and trending topics.
- Author cards with social media icons.
- Community section with benefits and testimonials.
- Newsletter subscription area in the footer.
- Hover effects and neo-brutalist visual styling.

## Built With

- HTML5
- CSS3
- Google Fonts – Exo 2
- Font Awesome 6.5.1

## How to Run

1. Download or clone this repository.
2. Make sure the `images` folder contains all required images.
3. Open `index.html` in your web browser.

No build tools or package installation are required.

## Website Sections

- **Home:** Introductory hero section.
- **Latest Articles:** Article cards, trending topics, and categories.
- **Authors:** Author profiles and social media links.
- **Community:** Community benefits and testimonials.
